# 蟾蜍（chanchu）图像版本来源记录

> 汉代（及西汉墓室壁画）中「月中蟾蜍 / 蟾蜍捣药」形象，共 4 个不同出土物版本。
> 注：Wikimedia Commons / archive.org 在本机网络不可达，图片均通过国内可访问页面引用的图片缓存（kimi-web-img.kimi.ai）下载，已逐张验证为真实图像并人工目检。

- v1.png ← https://kimi-web-img.kimi.ai/prod-data/online-image/search-upload/c22847f671723d72c88762acd781048c.png
  出处：河南南阳西关（小西关）东汉墓出土「嫦娥奔月」画像石拓片，南阳汉画馆藏（国家一级文物）。画面左上月轮内刻蟾蜍，右侧嫦娥人首蛇躯作飞升状。图片转引自北京中医药大学博物馆科普文《最丑捣药工？——汉画像石中的蟾蜍形象》图1：https://bowuguan.bucm.edu.cn/kpzl/ysmt/63933.htm

- v2.png ← https://kimi-web-img.kimi.ai/prod-data/online-image/search-upload/cd5c252e364412e1f7a9f12e3beea7ad.png
  出处：长沙马王堆一号汉墓 T 形帛画（非衣）左上角局部，西汉，湖南博物院藏。弯月之上绘蟾蜍（居中月轮内）与玉兔（左上）。图片转引自同上北中医博物馆文章图4「马王堆汉墓帛画局部」。

- v3.png ← https://kimi-web-img.kimi.ai/prod-data/online-image/search-upload/c687f28a6614f3dd311535f5c4d1174e.png
  出处：河南洛阳卜千秋墓主室顶脊壁画「月轮图」，西汉中晚期，洛阳古墓博物馆藏。圆形月轮内左侧绘蟾蜍、右侧绘桂树。图片转引自陈一飞《月宫桂树传说的文化意涵及视觉传承》图1（原载俞伟超主编《中国画像石全集》第7卷，2002）：https://cul.sohu.com/a/742777583_121856459

- v4.png ← https://kimi-web-img.kimi.ai/prod-data/online-image/search-upload/a63c0b18a5d810db9d63f5274a4d3eb3.png
  出处：四川出土汉画像砖「伏羲女娲」拓片及月轮局部，东汉。女娲（右）托举月轮，月内有蟾蜍与桂树（局部放大图中蟾蜍位于桂树左侧）。拓本为京都大学人文社会科学研究所藏中国石刻拓本资料（四川画像砖），图片转引自上文图6。
