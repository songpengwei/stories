# 凤鸟（fengniao）图像变体来源

- v1.jpg ← https://openaccess-cdn.clevelandart.org/1925.136/1925.136_print.jpg
  出处：克利夫兰艺术博物馆藏，西汉（公元前100–前1年）陶灶模型面板 "Panel from Model Cooking Stove: Vermilion Bird"（馆藏号 1925.136），陕西西安墓葬出土。模印浅浮雕朱雀/凤鸟，长尾华丽，昂首衔珠（丹）。
- v2.jpg ← https://openaccess-cdn.clevelandart.org/1982.260.c/1982.260.c_print.jpg
  出处：克利夫兰艺术博物馆藏，北齐（550–577年）石棺床围板（石板）"Section of a Coffin Platform: Phoenix"（馆藏号 1982.260.c）。高浮雕凤鸟/畏兽式大鸟，双翼展开、羽尾翻卷，上方饰莲瓣纹。
- v3.jpg ← https://openaccess-cdn.clevelandart.org/1995.315/1995.315_print.jpg
  出处：克利夫兰艺术博物馆藏，东汉至西晋（25–316年）铜镜 "Mirror with Paired Phoenixes"（馆藏号 1995.315）。镜背中央纽两侧铸对称双凤，带铭文，锯齿纹缘。
