# 西王母（xiwangmu）变体图像来源

逐行记录：文件名 ← 来源 URL + 出处说明。

- v1.jpg ← https://museum.sinica.edu.tw/_upload/image/collection_item/hd/4055eba4d2f91dc8.jpg
  （藏品页 https://museum.sinica.edu.tw/collection/5/item/635/ 「漢代的媽祖──西王母」）
  出处：东汉画像石拓本，山东嘉祥武氏祠，中研院历史语言研究所历史文物陈列馆藏。西王母戴胜、正面端坐于座上居中，两侧羽人侍立，有玉兔捣药、神兽环绕。1920×861，清晰。

- v2.jpg ← https://img.dpm.org.cn/Uploads/Picture/dc/59187[1024].jpg
  （藏品页 https://www.dpm.org.cn/collection/sculpture/233882.html ）
  出处：东汉「西王母车骑图画像石」（高62×宽80.5厘米，文物号 新00075855），故宫博物院藏。原石照片：上层西王母戴胜端坐正中，两侧跪拜者持嘉禾，有三足乌、九尾狐、羽人；下层车骑出行。右上角刻「画像丙」三字。1024×768，石面有风化但形象轮廓可辨。

- v3.jpg ← https://sum.scu.edu.cn/__local/4/F4/A4/52CC1FF5A30F64E3F12AD6B1973_0105554A_88E81.jpg
  （藏品页 https://sum.scu.edu.cn/info/1150/2165.htm ）
  出处：东汉「西王母画像砖」，四川大学博物馆藏。略呈正方形，西王母笼袖端坐于瓶形龛内龙虎座上，两侧云气缭绕，座前大蟾蜍起舞，左有三足乌、执棨戟侍立人物，右有持灵芝玉兔、九尾狐，下有跪拜人物。实物照片 1000×667，清晰。

- v4.jpg ← https://sum.scu.edu.cn/__local/C/46/ED/21BCE949F537A823838BD29FF2E_BB9E749E_77C63.jpg
  （藏品页 https://sum.scu.edu.cn/info/1150/2164.htm ）
  出处：东汉「西王母画像砖」（另一件，长方形砖，一侧饰画像），四川大学博物馆藏。西王母正面端坐，龙、虎分列左右为座（龙虎座），周围有仙人、三足乌、九尾狐、蟾蜍及跪拜人物。实物照片 1000×667，清晰。
