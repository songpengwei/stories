# 羽人（yuren）图像版本来源

共 4 张，均为不同出土物/不同版本，已逐张目验（形象清晰、可辨羽人轮廓，适合作抠图剪影参考）。

- `v1.jpg` ← https://p3.itc.cn/images03/20210718/c30b110ee8004a35b7d98cda6c761763.jpeg
  东汉"月神"画像砖拓片：羽人（人首鸟身、头梳髻）怀抱一轮明月（内有蟾蜍、桂树）凌空飞翔，上下各有星辰。1985 年四川彭州市义和乡搜集，原砖藏四川博物院；此拓为破禅室藏近拓，刊于《永宣金石——古代碑帖拓本选粹》（张永强编，西泠印社）。图源：搜狐《汉代画像砖之美》 https://www.sohu.com/a/478143108_121123711 （图角有搜狐打的马赛克斑块，不影响主体）

- `v2.jpg` ← https://p4.itc.cn/images03/20220508/21b06b5282f94a7c814b841f793ca69d.jpeg
  东汉"骑鹿升仙"画像砖（原砖照片）：右侧仙人骑白鹿回身伸手，左侧羽人短发大耳、肩背出羽、下着羽裙，一手托举药盘、一手前伸递药。四川彭州九尺乡（镇）征集，四川博物院藏。图源：搜狐"读图观史"刊贺西林《云崖仙使——汉代艺术中的羽人及其象征意义》图版（图一O） https://www.sohu.com/a/545012811_121124385

- `v3.jpg` ← https://p2.itc.cn/images03/20220508/d14eca0b465d4c85bd56911450ceb579.jpeg
  西汉墓室壁画羽人：侧面人形，大耳出颠，肩背生羽翼，身后拖长羽尾，作飞行状。西安理工大学西汉壁画墓出土（2004 年发掘）。图源：同上贺西林文图版（该文 2017 年新浪收藏版标作"图四 壁画 西安理工大学西汉墓" https://collection.sina.cn/2017-07-24/detail-ifyihrmf3267622.d.html ）

- `v4.jpg` ← https://p7.itc.cn/images03/20220508/835b52ac546d44a89883414673c17d79.jpeg
  东汉画像石拓片：人首兽身、身生羽翼的羽人，穿行于双龙（苍龙）云气之间。河南南阳麒麟岗东汉画像石墓出土。图源：同 v2 贺西林文图版（图七，该文新浪收藏版标作"图七 画像石(拓片) 河南南阳麒麟岗东汉墓"）
