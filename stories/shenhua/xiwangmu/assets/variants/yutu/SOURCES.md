# 玉兔捣药 (yutu) 变体图像来源

- v1.png ← https://www.dpm.org.cn/Uploads/File/2023/02/09/u63e48a5df1595.pdf —— 故宫博物院《紫禁城》杂志2023年第1期《中国古代的白兔崇拜》一文插图（PDF 第11页内嵌图，1015×248）：东汉画像石拓片，山东省嘉祥县宋山小石祠西壁画像。西王母居中端坐，左右两侧玉兔持杵与蟾蜍共同捣制不死药。
- v2.png ← https://p9.itc.cn/q_70/images03/20220910/f045f36aebc54dd3b2bd41e408bf4160.png —— 搜狐号"乐艺会"文章配图（2022-09，文章标题含"南阳汉画像石 玉兔捣药图拓片……陕西绥德汉画像石"，1080×1080）：汉画像石石面照片，单只玉兔直立、前肢持杵对臼捣药。
- v3.png ← https://p1.itc.cn/q_70/images03/20220910/99c14f335ae343fb9eecc3115a52487a.png —— 同上出处（944×1244）：东汉画像石拓片，带翼玉兔直立持杵捣药，右下为药臼，上方饰云气纹（陕北绥德/米脂一带"带翼玉兔"风格）。
- v4.jpg ← https://bkimg.cdn.bcebos.com/pic/a50f4bfbfbedab64034fca89de64b8c379310a55b062 —— 百度百科"玉兔捣药"词条概述图（945×944），标注来源：山东嘉祥汉画像石。拓片：两只带翼玉兔隔大臼相对而立、各持杵捣药。
