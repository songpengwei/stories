# 九尾狐（jiuweihu）图像版本来源

- v1.jpg ← https://wx1.sinaimg.cn/large/59219113gy1hx0m7kmhzij24ms30wx6y.jpg （经 https://www.sina.cn/news/detail/5125172552270026.html 转载的微博图床原图，摄影@木岛主）
  出处：东汉“西王母”画像砖，1955年四川成都新都新繁镇清白乡出土，四川博物院藏。整砖展厅照片（5313×3968）：西王母戴胜坐龙虎座，画面右侧即身生两翼、尾部上扬呈扇形多歧的九尾狐，轮廓清晰可抠。

- v2.png ← https://p8.itc.cn/q_70/images03/20221207/d03da3327d5f4fc19ce2818cbaaba2eb.png （搜狐转载 https://history.sohu.com/a/614788928_121107011 《观映丨西王母、东王公、九尾狐、三足乌……汉代铜镜里的神仙世界！》）
  出处：汉“长宜子孙”四乳神兽纹铜镜（直径16.5厘米，广东大观博物馆藏）上的九尾狐局部特写。狐形奔走，尾部分作多条卷曲尾绺。

- v3.png ← https://p3.itc.cn/q_70/images03/20221207/9dcd4d8dd5324cec95aa322d11f9d952.png （同上一篇文章）
  出处：汉神兽博局纹铜镜（直径13.7厘米，广东大观博物馆藏）上的九尾狐局部特写。狐身回首，尾部明确散作九股叉枝，是“九尾”最直观的一版。

- v4.jpg ← https://q6.itc.cn/q_70/images03/20250728/8eca44a52eb546b794abdd60dd0d44f5.jpeg （李忠民、张剑光《入冥与升仙：画像砖所见两汉身后世界的双重想象》，《学术月刊》2025年第7期图4，搜狐转载 https://www.sohu.com/a/918457552_121119368 ）
  出处：东汉“车骑出行与西王母”画像砖拓片，重庆南岸民间机构藏。田字格构图，右下格为玉兔捣药、羽人、三足乌与九尾狐（右缘圆身、背部放射状多尾者）。分辨率偏低（571×352），九尾狐形象较小但轮廓可辨。

备注：v1 与砖上九尾狐特写（同砖另一张照片）、新繁砖线图（mirror/44，带“九尾狐”标注）属同一出土物，未重复计数。偃师辛村新莽墓壁画《西王母与捣药玉兔、九尾狐、蟾蜍》仅找到 182×260 小图，不清晰，未采用。

## 抠图记录（cutout.py → c*.png）

- c1.png ← 对应 v1（新繁砖）。v1 为低对比度浮雕展厅照片，阈值法无法分离形体，改用同一出土物的拓片照片抠取：← https://q5.itc.cn/q_70/images03/20250728/075c3f0ba1a846d3a4e996252938b86d.jpeg （上文《学术月刊》文图6，新繁砖拓片）。参数 --crop 0.752,0.05,0.185,0.46 --thresh 115。
- v2 放弃：该图为展览线描插画（空心线条、绿底），阈值法只能得到断续线条，无法形成剪影。
- c3.png ← v3（博局镜九尾狐）。v3.png 本身带透明通道（透明像素转灰度后拉低均值导致自动反相），先平铺到白底再抠：--thresh 140。
- v4 放弃：九尾狐在原图中仅约 70×100 像素，多档 crop/thresh 后仍夹杂旁边羽人残笔，轮廓不干净。
